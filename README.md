# Traffic-Sign-Detection-Based-on-MobNetViT
本研究以交通标志检测为核心任务，基于MobileNetViT架构设计并实现轻量化、高精度的检测系统，具体内容和功能如下： 完成GTSRB交通标志数据集的预处理与优化，解决数据不平衡、图像质量差异、类别分类处理等问题，提升数据可用性。 模型通过融合MobileNet的轻量化与ViT全局特征建模能力，在精度与效率间实现平衡。利用MobileNet-ViT模型结构，增强对小尺寸、复杂背景下交通标志的特征提取能力，适配5大类交通标志（限速类、禁止类、指示类、警告类、其他类）分类任务。同时，通过添加分类模块进一步提升模型的分类能力，提高分类效率。
